# MVC_app_001 - Agenda Inteligente

## Descripción del sistema

Este proyecto es una aplicación web desarrollada con ASP.NET Core MVC.

El sistema permite administrar una agenda inteligente donde se pueden gestionar:

- Usuarios
- Eventos
- Categorías
- Recordatorios
- Auditorías

La aplicación utiliza Entity Framework Core para conectarse a una base de datos SQL Server.

APP_USER=admin
APP_PASSWORD=replace-with-a-secure-app-password

DB_SERVER=localhost
DB_NAME=AgendaInteligenteDb
DB_USER=agenda_user
DB_PASSWORD=replace-with-a-secure-database-password
DB_TRUST_SERVER_CERTIFICATE=True

- ASP.NET Core MVC
- Razor Views
- Entity Framework Core
- SQL Server
- .NET 10.0
